# Frederick Douglass: Chapters I–III source outline

Canonical text for this campaign: Frederick Douglass, _Narrative of the Life of Frederick Douglass, an American Slave. Written by Himself._ (1845), Chapters I–III. Primary transcript: <https://www.gutenberg.org/files/23/23-h/23-h.htm#link2HCH0001>. Retrieved for this project on September 22, 2026. The supplied Franklin PDF is not a source for Douglass.

The full three-chapter text was read before campaign writing. `src/douglass/source.json` preserves the paragraphs of the HTML edition, with whitespace normalized. Reference `C.P` means chapter C, paragraph P in that local transcript. The campaign deliberately emphasizes main ideas; the complete text is available in the source viewer for closer reading.

The first-person layout is fictional. The player investigates evidence in a reconstructed memory; the game does not pretend Douglass conducted an infiltration, attacked people, or altered the events. Moving veils are symbolic hazards, not historical guards. Finishing the campaign preserves the book’s outcomes.

## Audit rules

- Every authored dialogue line and quiz question cites one or more local paragraph references.
- Paraphrases are labeled. Exact speech is checked against the primary text and labeled as a reported exchange.
- No later literacy, Baltimore childhood, Covey fight, or escape episode is inserted into Chapters I–III.
- Questions have four distinct choices and a source-backed explanation; chapter-balanced exams select 7 + 7 + 6 questions from the 36-question bank.
- Movement score measures gameplay only. The final quiz separately measures understanding.
