# Source audit — Franklin: The Path to Print

Canonical source: the user-provided `Franklin Part 1.pdf` (27 scanned PDF spreads; printed Part One pp. 1–53). All 27 spreads were rendered at 1800px and visually read before game content authoring. Machine extraction returned zero characters on every page. PDF spread numbers, not printed page numbers, are used in `sourcePages`.

Only Part One prose and explicitly attributed material in these scans supplies facts. Obscured front matter on PDF page 1 is excluded. Editorial footnotes are not silently treated as Franklin's narrative. Historical uncertainty is retained. No outside factual sources, thirteen-virtue list, named anonymous persona, or unstated full names have been added. Scene atmosphere is illustrative; all dialogue is labeled paraphrase.
